# What changed

## 0.1.1 (13 October 2026)

- The Claude plugin carries the Prytan mark as its icon (`logo.png`) and the listing links the directory asks for
  (documentation, support, privacy policy, terms). Nothing else changed: the connector, the skill and the hooks are
  the same as in 0.1.0.
- If you installed 0.1.0 from the marketplace, Claude updates the plugin by itself (or run `claude plugin update
  prytan@prytan-plugins`); nothing to redo. If you uploaded the zip, you keep working as you are; upload the new zip
  only if you want the icon.

## 0.1.0 (9 October 2026)

- The first release: the connector, the memory skill and the hooks for Claude (Cowork, Claude Code), ChatGPT and
  Codex, Gemini CLI, and the snippets for VS Code, Cursor and Cline.
